MEU BRASIL — mapa de viagens

Este é um site estático para GitHub Pages. O mapa exige internet e carrega
dados municipais de github.com/tbrugz/geodata-br.

As cidades marcadas funcionam com backup local no navegador. Depois de
configurar o Firebase e entrar com Google, elas são sincronizadas entre
navegadores na mesma conta.

Leia README.md para configurar Firebase Authentication, Firestore, regras de
segurança e GitHub Pages. Publique também firestore.rules no Firebase Console.
