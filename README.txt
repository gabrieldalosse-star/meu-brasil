MEU BRASIL — site estático

Publicação: envie index.html a uma hospedagem estática como Netlify Drop ou GitHub Pages.
O mapa exige internet e carrega dados municipais de github.com/tbrugz/geodata-br.
Os dados de visita ficam no armazenamento local do navegador; exporte backups regularmente.
Esta versão não possui login nem sincronização entre dispositivos.
